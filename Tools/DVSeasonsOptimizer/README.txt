DVSeasons Optimizer 0.1.1

Purpose:
- Safe diagnostic/performance add-on for DVSeasons 0.3.3 GitHub(10)-style vehicle snow code.
- Forces part-level scheduler decisions off so the vehicle-level scheduler is used.
- Uses reflection/Harmony, so DVSeasons itself is not overwritten.

Install:
1. Keep the normal DVSeasons mod installed.
2. Copy folder DVSeasonsOptimizer into Derail Valley/Mods/.
3. Start the game.
4. Check Player.log for:
   [DVSeasonsOptimizer] Loaded.
   [DVSeasonsOptimizer] DVSeasons vehicle scheduler optimizer active.

Remove:
Delete Derail Valley/Mods/DVSeasonsOptimizer.

This build intentionally does NOT mutate DVSeasons' Part lists or fake LOD state. The previous claimed 0.1.0 archive was never actually attached; 0.1.1 is the first real packaged build.
