# Исходный код в GitHub-пакете

Каталог `DVSeasons/Source` содержит C#-проекты, тесты, документацию, инструменты, визуальные эталоны и полный Unity-проект сезонных ресурсов. Готовый runtime лежит в родительском каталоге `DVSeasons`.

Пакет хранится в одном `DVSeasons-<version>-GitHub.zip`. Качество текстур и состав проекта не меняются.

Из GitHub-пакета исключены только генерируемые `bin`, `obj`, Unity-кэши, PDB, результаты сборки и вложенные архивы. PowerShell/Python-инструменты и визуальные эталоны остаются в `Source`, но не входят в Nexus-пакет.

Перед загрузкой в GitHub распакуйте ZIP и загрузите его содержимое. Ограничение применяется к отдельным файлам в репозитории, поэтому общий размер локального ZIP может превышать 100 МБ. Упаковщик проверяет каждый source/runtime-файл и каждую запись ZIP по распакованному размеру; значение 100 000 000 байт и больше считается ошибкой.

Прямая сборка после распаковки общего архива:

```powershell
dotnet build .\Source\DVSeasons.Game\DVSeasons.Game.csproj -c Release -p:DVInstallDir="D:\Games\Derail Valley"
```
