# DVSeasons 0.3.15

- Исправлена оставшаяся причина смещения наледи при движении поезда, дверей и форточек. Рисунок рассчитывается непосредственно из локальных вершин стекла или его готовых UV, без преобразования через мировые координаты.
- Привязка больше не зависит от того, сдвинулся ли поезд или открылась ли дверь после обновления материала, но до отрисовки кадра. Для этого эффекта отключено объединение геометрии, меняющее локальные координаты вершин.
- Сохранены состояния замерзания, оттаивания, снега и дворников из 0.3.14.

Проверка воспроизводит позднее движение после установки параметров материала: поступательное движение, поворот двери, сдвиг форточки и перенос начала координат. На шейдере 0.3.14 эта проверка выявляет смещение; новый шейдер проходит её в обоих режимах UV. Полный игровой прогон не выполнялся.

Архив установки: `DVSeasons-0.3.15-Nexus.zip`. Архив с исходниками для GitHub: `DVSeasons-0.3.15-GitHub.zip`.
