# DVSeasons 0.3.25

- Клиенты получают фактическую плотность снежного покрова хоста, включая состояние из сохранения.
- Ручное переключение сезона, включая повторный выбор зимы, сбрасывает сезонные эффекты и инициализирует снег у клиентов ровно один раз.
- При завершении загрузки клиента повторно передаются сезон и отопители. Изменения отопителя, сделанные во время загрузки, больше не пропускаются.
- Отключившиеся игроки удаляются из рассылки; старые обработчики отключаются при завершении сервера. Переподключение начинает приём пакетов заново.
- Дополнительная сезонная физика двигателей, аккумуляторов, температур и тормозов выполняется только на хосте. Защита температурных ламп от отрицательных показаний остаётся у клиентов.

Проверено с установленным Multiplayer **0.1.16.0**: 200 автоматических тестов, включая модель хоста и двух клиентов с производственным сериализатором, и проверки в Unity с DLL игры. Живая сессия на нескольких компьютерах не проверялась.

У хоста и клиентов должен быть DVSeasons **0.3.25**: сетевой протокол обновлён до 8. Индивидуальные маски наледи, следы дворников, проталины и расположение частиц остаются локальными — подробнее в [отчёте](MULTIPLAYER_0.1.16.md).

Файлы: `DVSeasons-0.3.25-Nexus.zip` для установки; `DVSeasons-0.3.25-GitHub.zip` с исходниками для загрузки содержимого на GitHub. Архивы цельные, каждый отдельный файл внутри меньше 100 МБ.
