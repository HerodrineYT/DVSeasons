# DVSeasons 0.2.7 — исправление зимних поверхностей

- Удалены вспомогательные поверхности льда для луж, которые в 0.2.6 могли пересекать здания, корабли и землю и выглядеть как огромные снежные треугольники.
- Лёд на лужах теперь наносится в экранном проходе по маске WetStuff, без создания геометрии в мире. Общая влажность и штатные лужи сохраняются.
- Для водоёмов добавлен отдельный шейдер с повторением текстуры в мировых координатах. Используется исходная геометрия воды; слой льда оставляет видимыми её цвет и отражения.
- Исправлена загрузка шейдеров из AssetBundle при использовании открытых PNG-текстур.
- Сохранены плавное появление и таяние льда, а также отключение дождевых кругов зимой.

## Проверки перед выпуском

- Release-сборка: 0 ошибок, 0 предупреждений; 42 автоматических теста пройдены.
- Unity 2019.4.40f1: оба шейдера из собранного AssetBundle поддерживаются видеокартой. Внеэкранная проверка пикселей прошла для 0%, 50% и 100% льда, ориентации изображения, сохранения сухих участков и альфа-канала.
- AssetBundle: 165 ресурсов; после LZMA-перепаковки оба вложенных файла побайтно совпадают с результатом Unity.
- Проверены официальные ленты интеграций: Multiplayer 0.1.15.8, DoubleTrack 2.1.1 и PassengerJobs 5.3.0 соответствуют установленным версиям.

Игра при подготовке исправления не запускалась. Внешний вид на реальных лужах и водоёмах ещё требует проверки после полного перезапуска игры; автоматические проверки не заменяют эту проверку.
