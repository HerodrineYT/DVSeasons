# DVSeasons 0.2.37 — шаги учитывают таяние на локомотиве

- Мод получает точный коллайдер под ногами из того же метода игры, который определяет поверхность шага; дополнительный физический запрос на каждый шаг не выполняется.
- На работающем паровозе после полного таяния снова используются штатные шаги.
- Частично заснеженные тепловозы продолжают использовать запись снега, пока покрытие заметно.
- Тендер и соседние локомотивы имеют независимое состояние снега.
- После остывания и восстановления покрова во время снегопада пользовательский звук возвращается.
- Первое подавление снежного звука на очищенном локомотиве записывается в `Player.log` один раз без спама.

Архивы: `DVSeasons-0.2.37-Nexus.zip` и `DVSeasons-0.2.37-GitHub.zip` (второй включает исходники).
