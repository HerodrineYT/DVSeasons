# DVSeasons 0.3.16

- Наледь постепенно исчезает при прогреве стекла от 0 до +5 °C. Убрано мгновенное обнуление видимого слоя при достижении +5 °C; при этой температуре стекло по-прежнему полностью свободно от льда.
- Осевший снег также плавно теряет видимость при прогреве, включая снег, восстановленный из сохранения.
- Запотевание плавно исчезает в диапазоне +8…+12 °C вместо резкой отсечки при +12 °C.
- При смене сезона уже холодное стекло завершает прогрев по собственной температуре, без мгновенного удаления эффекта по температуре наружного воздуха.
- Сохранена привязка наледи к движущимся дверям и форточкам из 0.3.15.

Проверки: 168 тестов модели и интеграции; GPU-проверка последовательных температур для наледи, снега и запотевания, а также привязки к движущимся стёклам. На шейдере 0.3.15 новый тест воспроизводит скачок при +5 °C. Полный игровой прогон не выполнялся.

Для Nexus: `DVSeasons-0.3.16-Nexus.zip`. Для GitHub с исходниками: `DVSeasons-0.3.16-GitHub.zip`. Каждый файл внутри архивов меньше 100 МБ.
