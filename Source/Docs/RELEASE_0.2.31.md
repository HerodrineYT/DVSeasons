# DVSeasons 0.2.31 — реалистичный снежный шлейф

- Вместо одинаковых круглых частиц используются четыре процедурно созданные формы рыхлой снежной пыли с неоднородной плотностью и мягкими краями.
- Шлейф сначала образует компактное ядро над путём, затем клубы расширяются, слегка поднимаются, теряют прозрачность и сносятся фактическим ветром.
- Генерация по пройденному расстоянию сохраняет непрерывную плотность при разной скорости и частоте кадров. Лимит снижен до 600 частиц, столкновения по-прежнему отключены.

Архивы: `DVSeasons-0.2.31-Nexus.zip` и `DVSeasons-0.2.31-GitHub.zip` (второй включает исходники).
