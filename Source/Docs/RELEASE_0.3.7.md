# Dynamic Seasons 0.3.7

## Исправления осенней листвы

- Листья больше не становятся прозрачными при приближении игрока: рендерер использует шейдер без включённого в игре soft-particle depth fade.
- Цвет тела листа теперь полностью непрозрачный; сглаживание сохраняется только на его краях.
- Осевшие листья больше не удаляются по таймеру через 58–105 секунд и остаются на земле, пока находятся в активной области симуляции.
- Листья с низких крон сразу укладываются на найденную поверхность, если рассчитанная точка старта оказалась у земли.
- Длительное падение теперь завершается посадкой на последнюю корректно найденную поверхность вместо удаления листа.

## Ветер и производительность

- Лежащие листья реагируют на направление и скорость штатного ветра Derail Valley: при слабом ветре они перекатываются, при сильном ненадолго поднимаются в воздух.
- Ветровой подъём ограничен 18 листьями в секунду, двумя листьями за кадр и 48 кандидатами на один проход.
- Ветер не добавляет физических запросов; общий лимит поиска поверхностей остаётся равным 10 raycast-запросам за кадр.

## Деревья

- Пни, стволы, ветви, корни, валежник и другая древесина исключены из осенней перекраски листвы.
- Исправлен ярко-оранжевый пень `prefab_beech_forest_stump_01_2`: его общая текстура снова сохраняет исходный цвет на всех LOD.
