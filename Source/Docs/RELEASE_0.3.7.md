# DVSeasons 0.3.7

- Выбросы у колёс получили материал с тем же оттенком, освещением и снижением яркости, что и динамический снег. Убрано повторное затемнение частиц и наследование материала обычной пыли. Новый материал используется и для основного снежного шлейфа.
- Наличие снега проверяется отдельно под левым и правым колесом. На очищенной рельсине выброс не появляется; если снег есть только на одной стороне, выброс будет только с этой стороны.
- Проверка учитывает следы предыдущих колёс, сохранённые очищенные участки и их постепенное заполнение при новом снегопаде. При неполном покрытии учитывается рисунок снежных и голых участков.
- Частицы появляются непосредственно у контакта колеса с рельсом. Проверка укрытия выполняется для соответствующей стороны оси.

Для определения очищенных мест используется индекс тех же полос, которые убирают видимый снег с рельсов. Индекс ограничен существующим объёмом истории следов и освобождает записи вместе с ними. Проверки выбросов выполняются только вблизи камеры.

Проверено: сборка без предупреждений и ошибок, 202 теста, 44 перевода. В Unity проверены цвет относительно освещённой снежной поверхности, разные условия освещения и снижение яркости, сохранение прозрачности текстуры, независимые стороны оси, отсутствие выбросов на очищенных рельсах, на стоянке, при появлении/скачке положения и под тестовой крышей. Проверены продление следов, разделение путей по высоте, сохранение/восстановление, новый снегопад, перенос начала координат и частичное покрытие. Полная игровая сессия не запускалась.
