# DVSeasons 0.2.27 — загрузка снега без блокировки Multiplayer

Тяжёлый Unity AssetBundle объёмом около 106 МБ теперь читается через `AssetBundle.LoadFromFileAsync`, поэтому подготовка сезонных шейдеров не останавливает главный поток игры на несколько секунд.

При установленном Multiplayer визуальная часть DVSeasons начинает подготовку через четыре секунды после загрузки мира. Поиск обычных материалов, поиск terrain-материалов и запуск процедурного слоя выполняются в разных кадрах. Ближняя и дальняя карты формы поверхностей также впервые строятся в разных кадрах.

Фильтр повторяющихся предупреждений Multiplayer включается только вместе с runtime DVSeasons и сразу отключается при выключении мода. Это позволяет проверить исходные сообщения Multiplayer с отключённым DVSeasons и исключает скрытое вмешательство неактивного мода.

Проверка: проект собран без предупреждений и ошибок; пройдены 98 автоматических тестов.

Архивы: `DVSeasons-0.2.27-Nexus.zip` и `DVSeasons-0.2.27-GitHub.zip` (второй включает исходники).
