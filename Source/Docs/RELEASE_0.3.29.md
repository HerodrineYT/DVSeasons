# DVSeasons 0.3.29

Усилен эффект снижения дневного пересвета снега. Ползунок теперь имеет диапазон 0–200%: при 100% используется прежняя усиленная коррекция, при 200% применяется максимальное сжатие ярких нейтральных участков и более тёмный снежный материал. Значение 0 полностью отключает дополнительную коррекцию.

Коррекция по-прежнему плавно зависит от освещения и покрытия, не работает на небе и насыщенных цветах, сохраняет альфа-канал и детали между уровнями яркости. Добавленное усиление затрагивает только дневную заснеженную сцену.

Проверено: сборка без ошибок и предупреждений, 202 теста, GPU-проверка шейдера с максимальным уровнем 200%. Архивы цельные, каждый файл внутри меньше 100 МБ.

Nexus: `DVSeasons-0.3.29-Nexus.zip`. GitHub: `DVSeasons-0.3.29-GitHub.zip`.
