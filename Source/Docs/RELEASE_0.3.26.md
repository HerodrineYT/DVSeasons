# DVSeasons 0.3.26

В настройки добавлен переключатель «Насекомые и их звуки» (Insects and their sounds). По умолчанию включён. Выключение убирает пчёл и бабочек, останавливает жужжание и поиск мест появления насекомых; включение возобновляет их появление при подходящих весенних условиях.

Выбор сохраняется обычной кнопкой Save в Unity Mod Manager. Настройка локальная: в мультиплеере каждый игрок выбирает её самостоятельно. Сетевой протокол 8 не менялся.

Файлы: `DVSeasons-0.3.26-Nexus.zip` для установки, `DVSeasons-0.3.26-GitHub.zip` с исходниками. Архивы цельные, каждый файл внутри меньше 100 МБ.
