# DVSeasons 0.3.24

Количество осенних листьев по умолчанию установлено в «Без ограничений» — крайнее правое положение ползунка. При желании можно выбрать конечный лимит в настройках мода.

Новый вариант применяется при создании настроек или отсутствии поля количества листьев. Ранее сохранённый выбор сохраняется при обновлении.
