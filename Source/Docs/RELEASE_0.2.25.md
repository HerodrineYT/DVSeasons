# DVSeasons 0.2.25 — исправление таяния снега на локомотивах

Исправлена связь динамического снега с состоянием локомотива. Для дизельных локомотивов мод сначала читает штатный `engineOnReadOut`, затем ищет соответствующий порт во всём графе симуляции и использует обороты двигателя как запасной признак. Источник машины теперь также определяется через родительский `TrainCar`, если реестр передал дочерний компонент.

Таяние стало заметнее в течение первой минуты:

- паровоз очищается полностью примерно за 30 секунд после появления огня или прогрева котла;
- дизель снимает до 30% покрытия примерно за 45 секунд;
- на BE2 снег по-прежнему не тает;
- выпавший после остановки снег восстанавливает ранее растаявшее покрытие.

В журнал добавлены редкие диагностические строки только при привязке двигателя, смене его состояния и прохождении четверти диапазона таяния. Они позволяют увидеть тип локомотива, найденный порт и фактический процент снятого покрытия без постоянной записи каждый кадр.

Проверки: 97 модульных тестов, сборка против DLL Derail Valley build 99 без предупреждений, проверка загрузки сборки и регрессия Unity для динамического снега и угля. Ошибки `Multiplayer.Components.Networking.Train.NetworkedTrainCar` из предоставленного журнала относятся к Multiplayer и загрузке кабины; стеков DVSeasons среди них нет.

Архивы: DVSeasons-0.2.25-Nexus.zip и DVSeasons-0.2.25-GitHub.zip (второй включает исходники).
