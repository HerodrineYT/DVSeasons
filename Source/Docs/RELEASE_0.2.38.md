# DVSeasons 0.2.38 — штатные шаги после таяния

- Состояние снега для звука берётся из того же точного коллайдера, который уже выбрала игра для шага.
- Для внешних частей и отсоединённых кабин учитывается иерархия `TrainCar.interior`/`interiorLOD`, поэтому работающий паровоз больше не звучит как заснеженный после полного таяния.
- При нулевом остатке покрытия на конкретном локомотиве штатный звук сохраняется; тендер и другие вагоны не затрагиваются.
- После остывания и восстановления покрова во время снегопада пользовательская запись возвращается автоматически.
- Дополнительных лучей или проверок каждый кадр нет: обработка выполняется только в момент события шага.

Архивы: `DVSeasons-0.2.38-Nexus.zip` и `DVSeasons-0.2.38-GitHub.zip` (второй включает исходники).
