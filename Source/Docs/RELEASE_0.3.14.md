# DVSeasons 0.3.14

- Наледь больше не ограничена 32 ближайшими окнами и радиусом 90 м. Обрабатываются загруженные наружные и внутренние стёкла; эффект следует за уровнями детализации стекла.
- Рисунок наледи закреплён на геометрии двери или форточки. Для стёкол с готовыми UV используются их собственные координаты. При подгрузке кабины наружное стекло подхватывает её дворники.
- При охлаждении стекла наледь постепенно нарастает; слабый мороз даёт меньшее покрытие, чем сильный. Имеющаяся наледь не тает при отрицательной температуре стекла.
- При +5 °C **самого стекла** наледь и прилипший снег полностью исчезают. Запотевание — отдельное состояние; при +12 °C стекла оно также исчезает полностью. Температура стекла меняется с задержкой относительно воздуха кабины.
- В игровое сохранение добавлены количество снега, протаявшие локомотивы, локальные маски снега на подвижном составе, очищенные колёсами рельсы, температура кабин и стёкол, снег и следы дворников на окнах. Сезон и точная фаза перехода сохраняются в том же игровом сохранении. Старые сохранения без новых данных продолжают открываться.
- Маски снега копируются асинхронно при изменении и сжимаются без потерь. Сохранение ждёт только незавершённые копии самого мода. Вне игры и в сухую погоду очищенные рельсы не засыпаются; снегопад продолжает их восстановление после загрузки.
- Динамическое покрытие расширено до дальности игровой камеры. Подробные карты вблизи сохранены, для дальней загруженной геометрии добавлена отдельная карта. Мод не заставляет игру загружать отсутствующие участки мира и не повышает её дальность камеры.
- H1 исключена из накопления листвы, включая выбор случайных поверхностей и попадания при падении листьев.

Новые данные записываются при следующем обычном сохранении/автосохранении игры. В мультиплеере запись принадлежит хосту; отдельная синхронизация масок снега между клиентами этим обновлением не добавлена.

Проверки: 167 автоматических тестов, GPU-проверки полного оттаивания и движения стекла, побайтовое восстановление маски снега, сохранение следов рельсов со сдвигом начала координат, восстановление снега при осадках, покрытие на расстоянии 2,4 км. Полный игровой прогон и сетевая сессия не выполнялись.

Для установки: `DVSeasons-0.3.14-Nexus.zip`. Для загрузки содержимого в GitHub: `DVSeasons-0.3.14-GitHub.zip`. Каждый файл внутри архивов меньше 100 МБ.
