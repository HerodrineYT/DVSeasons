# Dynamic Seasons 0.3.12

- Рабочие органы управления отоплением DE2, DM3, DH4 и DE6 перенесены из DVSurvival в Seasons. Используется существующая геометрия кабин; на DM3 сохранён регулятор из последней версии DVSurvival. Штатный Heating Rotary DM1U остаётся штатным.
- Seasons самостоятельно сохраняет положение отопителя каждого локомотива. При первом запуске подхватываются записи `CabHeaters` из сохранения DVSurvival, если собственных записей ещё нет.
- Обогрев стёкол использует подтверждённое положение переключателя. Выключение эффекта обледенения в настройках не отключает сами органы управления отоплением.
- В мультиплеере переключение подтверждает хост; запрос разрешён только для локомотива, который занимает игрок. Состояния передаются подключившимся клиентам и повторно запрашиваются после загрузки мира.
- Протокол Seasons обновлён до 7: всем участникам сессии нужна одинаковая версия мода.
- Для совместной установки обновлён DVSurvival до 0.9.15: он использует отопитель Seasons, не создаёт второй переключатель и не перезаписывает его состояние старыми данными. Без Seasons сохранено самостоятельное отопление Survival.

Проверки: сборка, 159 тестов Seasons (включая раздельные состояния локомотивов, сетевой формат и проверку доступа), 290 тестов Survival, переводы. Физическое взаимодействие с переключателями и совместная сессия требуют проверки в игре.

Архивы: `DVSeasons-0.3.12-Nexus.zip` и `DVSeasons-0.3.12-GitHub.zip`. Для пользователей обоих модов: `DVSurvival-0.9.15-Nexus.zip` и `DVSurvival-0.9.15-GitHub.zip`.
