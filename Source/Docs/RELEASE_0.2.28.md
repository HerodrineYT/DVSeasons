# DVSeasons 0.2.28 — чистый журнал при работе со снегом и Multiplayer

Обработчик снега на угле теперь сначала проверяет настоящий тип свойства `_MainTex` в шейдере. Это устраняет сотни предупреждений Unity `Material doesn't have a texture property '_MainTex'`, которые появлялись при обходе материалов локомотивов и тендеров.

Добавлена узкая защита для известной ошибки Multiplayer 0.1.15.8 при выгрузке мира. Она подавляет только `NullReferenceException` из `NetworkedPitStopStation.OnDisable/OnDestroy`, `NetworkedPluggableObject.OnDisable/OnDestroy` и патча кассового аппарата, только когда `UnloadWatcher.isUnloading` уже установлен игрой. Исключения этих методов в обычной работе и все остальные ошибки остаются видимыми.

Проверка журнала 0.2.27 также подтвердила, что асинхронная загрузка работает в нужном порядке: предупреждение Multiplayer `PollEvents took 759 ms` произошло до запуска сезонного AssetBundle; затем пакет загрузился асинхронно и этапы снегового покрытия завершились отдельно. Постоянная CPU-нагрузка DVSeasons по встроенному профилю составляла примерно 0,2–0,3 мс на кадр, а максимальный стартовый CPU-пик снеговой подготовки — 18,37 мс.

Проверка: проект собран без предупреждений и ошибок; пройдены 98 автоматических тестов.

Архивы: `DVSeasons-0.2.28-Nexus.zip` и `DVSeasons-0.2.28-GitHub.zip` (второй включает исходники).
