# DVSeasons 0.2.29 — один слой льда и видимое таяние на дизелях

- В материале озёр ледяная normal-текстура теперь используется только в одном wave-слоте. Второй водяной слой плавно затухает при замерзании, поэтому больше не рисует смещённую копию трещин.
- Для процедурного снега на локомотивах частичное таяние дизелей теперь преобразуется в заметное уменьшение видимого слоя. На DM1U, DH4 и DE6 после полного прогрева остаётся половина интенсивности снежного покрытия; индивидуальный сигнал работающего двигателя и прежние исключения для паровозов и BE2 сохранены.

Архивы: `DVSeasons-0.2.29-Nexus.zip` и `DVSeasons-0.2.29-GitHub.zip` (второй включает исходники).
