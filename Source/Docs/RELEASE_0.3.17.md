# DVSeasons 0.3.17

- Возвращён выраженный морозный узор с кристаллами на полностью и частично замёрзших стёклах. В 0.3.16 температурное сглаживание слишком рано сокращало площадь узора.
- Площадь наледи снова меняется по мере таяния её слоя. Дополнительное температурное сглаживание меняет прозрачность узора, сохраняя форму кристаллов: от +2 до +5 °C температуры стекла он плавно исчезает. При +5 °C льда и осевшего снега по-прежнему не остаётся.
- Сохранены плавное исчезновение запотевания, работа дворников, сохранения и привязка к движущимся дверям и форточкам.

Проверки: 169 тестов модели и интеграции. GPU-проверка отдельно контролирует сохранность рисунка при оттаивании, плавность переходов, полное очищение при +5 °C и привязку к движущемуся стеклу. На шейдере 0.3.16 новая проверка воспроизводит потерю рисунка. Полный игровой прогон не выполнялся.

Для Nexus: `DVSeasons-0.3.17-Nexus.zip`. Для GitHub с исходниками: `DVSeasons-0.3.17-GitHub.zip`. Каждый файл внутри архивов меньше 100 МБ.
