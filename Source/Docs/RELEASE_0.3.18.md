# DVSeasons 0.3.18

- Дворники очищают мутный слой, остающийся на стекле после оттаивания кристаллов. Очистка следует за щёткой; за пределами её траектории слой сохраняется.
- Используется существующая маска очистки стекла. Она сохраняется вместе со снегом и постепенно восстанавливается при повторном замерзании. Дополнительные текстуры и расчёты физики не добавлены.
- Сохранены морозный узор, плавное оттаивание, очистка снега и привязка к движущимся дверям и форточкам. Твёрдую наледь на холодном стекле дворник по-прежнему не снимает.

Проверки: 169 тестов модели и интеграции; GPU-проверка очищенной и нетронутой частей стекла после оттаивания, а также существующие проверки рисунка, плавности и движения стекла. На шейдере 0.3.17 новый тест подтверждает, что мутный слой оставался в области прохода дворника. Полный игровой прогон не выполнялся.

Для Nexus: `DVSeasons-0.3.18-Nexus.zip`. Для GitHub с исходниками: `DVSeasons-0.3.18-GitHub.zip`. Каждый файл внутри архивов меньше 100 МБ.
