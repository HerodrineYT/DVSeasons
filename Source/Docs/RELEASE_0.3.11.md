# Dynamic Seasons 0.3.11

- Исправлен расчёт снега на скосах крыши локомотивов, включая DE6: наклон определяется с учётом геометрии, а не только карты нормалей краски.
- В настройки добавлен ползунок количества листьев: от 100 до 20 000, крайнее правое положение — «Без ограничений». По умолчанию сохранено 2200. Память увеличивается по мере появления листьев; создание и запросы поверхности по-прежнему распределены по кадрам. Ограничение дальности обработки сохраняется.
- Добавлена включённая по умолчанию настройка зимнего обледенения стёкол. Каждый локомотив имеет собственную модель температуры отопителя, воздуха кабины и стекла с постепенным прогревом и остыванием.
- Холодное стекло покрывается инеем. При обогреве оно оттаивает, затем запотевает и очищается, оставляя штатное отображение дождевых капель. Открытые двери и окна ускоряют охлаждение.
- Используются доступные органы управления отоплением, включая Heating Rotary DM1U и переключатели CabHeater от DVSurvival; дополнительная обязательная зависимость не требуется. Если доступного управления отопителем нет, он считается выключенным. На паровозе источником обогрева служит горящая топка.
- Ближайшие снежинки проверяются на пересечение со стеклом с учётом движения локомотива и оставляют снежные пятна. Дворники очищают их по своей фактической траектории; твёрдый иней должен сначала оттаять. Внутреннее запотевание дворник не убирает.
- Для стёкол используются небольшие маски без чтения данных с GPU и только ближайшие окна. Штатные материалы капель не заменяются.

Проверено: сборка без предупреждений, 151 автоматический тест, 36 строк перевода, GPU-отрисовка замёрзшего/оттаивающего/запотевшего/чистого стекла, снежных пятен и маски очистки. Внешний вид на реальном DE6, взаимодействие с конкретными дворниками и производительность требуют проверки в игровой поездке; редакторская сцена не заменяет её.

Файлы релиза: `DVSeasons-0.3.11-Nexus.zip` для установки и `DVSeasons-0.3.11-GitHub.zip` для публикации распакованного содержимого с исходниками. Упаковщик проверяет, что каждый файл внутри меньше 100 000 000 байт.
