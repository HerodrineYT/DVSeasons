# DVSeasons 0.3.28

В настройки добавлен ползунок «Снижение яркости снега» (0–100%, по умолчанию 100%). Значение 0 возвращает прежнюю картинку. Выбор сохраняется через Save в Unity Mod Manager и остаётся локальным в мультиплеере.

Днём снижается отражательная способность динамического снега, а яркие малонасыщенные поверхности проходят через плавную кривую сжатия яркости перед штатной постобработкой игры. Это сохраняет различия между светлыми оттенками вместо сплошной белой заливки. Коррекция изображения работает также с сезонными текстурами и дальним рельефом. Она может затронуть другие яркие белые поверхности в заснеженной сцене; это не точная маска только снежных пикселей.

Небо исключено по глубине, тёмные поверхности и насыщенные цвета сохраняются. Изменения плавно ослабевают с уменьшением освещения и количества снега. При нулевом эффекте дополнительный проход камеры снимается; после отключения мода ресурсы освобождаются. Общие настройки экспозиции, погоды и времени игры не изменяются. Полноэкранная коррекция добавляет копирование буфера и один проход GPU; влияние на FPS на компьютере игрока не измерено.

Проверено: сборка без ошибок/предупреждений; 202 теста; GPU-проверка нового шейдера в Unity 2019.4.40f1 — сохранение деталей HDR, холодного оттенка снега, исключение неба/теней/насыщенных цветов, неизменность альфа-канала и исходная картинка при нуле. Сборка AssetBundle также проходит проверки льда, наледи, листвы и весеннего рельефа. Конкретная сцена со скриншота в игре не воспроизводилась.
