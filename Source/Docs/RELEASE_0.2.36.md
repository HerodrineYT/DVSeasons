# DVSeasons 0.2.36 — восстановлено воспроизведение снежных шагов

- Исправлена проверка укрытия, которая могла принимать коллайдер самого игрока за потолок и оставлять только штатные шаги.
- Луч укрытия теперь игнорирует всю иерархию игрока, небольшие предметы, провода и ветки.
- Кабины и помещения по-прежнему распознаются по крупной низкой крыше.
- При первом фактически заменённом шаге в `Player.log` один раз появляется подтверждение `Custom snow footstep playback confirmed`; повторяющегося спама нет.
- Сборка и упаковщик теперь отдельно проверяют наличие обоих WAV-файлов.

Архивы: `DVSeasons-0.2.36-Nexus.zip` и `DVSeasons-0.2.36-GitHub.zip` (второй включает исходники).
