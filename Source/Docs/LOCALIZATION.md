# Переводы DVSeasons через Language Helper

Начиная с 0.3.1 требуется **DV Language Helper 1.2.1+** (`Id: DVLangHelper`). Unity Mod Manager проверяет зависимость и загружает её раньше DVSeasons. Установите Language Helper отдельно; архивы DVSeasons не содержат копий сторонних DLL.

Интерфейс получает строки из `Localization/DVSeasons.csv` через `TranslationInjector` Language Helper и игровую систему I2. В комплекте русский и английский; язык следует настройке игры. Для отсутствующего перевода используется английский. Диагностические сообщения `Player.log` остаются на английском.

**Свой перевод**

1. Откройте настройки Language Helper в Unity Mod Manager.
2. Найдите источник **DVSeasons** и нажмите **New Override File**, затем **Open Folder**.
3. Отредактируйте `DVLangHelper/override/DVSeasons.csv` в UTF-8. Сохраните имена ключей; заполните нужные языковые столбцы, например `Russian` или `French`.
4. Нажмите **Reload** для DVSeasons либо **Reload Overrides**. Текст в настройках DVSeasons читается заново при отрисовке. Если обновление не отобразилось, перезапустите игру, как рекомендует Language Helper.

CSV использует запятую как разделитель. Строки с запятыми заключайте в двойные кавычки, а двойные кавычки внутри значения удваивайте. Названия языков должны соответствовать Language Helper. Не переводите `Key` и имена ключей с префиксом `DVSeasons/`.

Сохраняйте подстановки целиком: `{0}`, `{1}`, `{2:F0}`, `{0:F2}`. Их можно переставлять вместе с фразой, но нельзя удалять или менять номер. Форматированные предложения хранятся целиком, поэтому перевод не привязан к порядку слов русского или английского. Числа форматируются по языку игры.

Пример файла замены одной строки:

```csv
Key,Description,Russian
DVSeasons/Settings.NewSnow,,Динамический снежный покров
```

Исходный CSV проекта находится в `Resources/Runtime/Localization/DVSeasons.csv`. После редактирования запустите `Tools/verify_localization.ps1`, затем обычную сборку. В GitHub-пакете готовый CSV находится рядом с runtime в `DVSeasons/Localization`; исходный проект умеет брать его оттуда при пересборке.
