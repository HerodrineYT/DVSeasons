# DVSeasons 0.3.27

- Исправлено включение и выключение отопителей клиентами Multiplayer 0.1.16. Сервер теперь узнаёт игрока по PlayerId: MP создаёт новый ServerPlayerWrapper для каждого внешнего пакета, поэтому прежнее сравнение объектов по ссылке отклоняло команды уже подключённого клиента. Подтверждённое состояние рассылается участникам, а повторный запрос получает ответ даже при неизменившемся положении.
- Температура кабины учитывает двери и форточки в постоянной кабине, внешних интерактивных объектах и отдельно расположенные проёмы, указанные в контроллере. Положение можно прочитать и до инициализации DoorsAndWindowsController. Открытие прогретой кабины охлаждает её при работающей печке; открытая холодная кабина прогревается медленнее закрытой.
- Полный поиск компонентов каждой кабины больше не повторяется каждые две секунды. После первичной привязки и одного повторного прохода поиск возобновляется при смене загруженных объектов или симуляции.
- Для снимков снега на вагонах переиспользуется буфер. Обновление маски больше не создаёт новый массив на 128 КБ и новую запись сохранения при каждом GPU readback. Сжатая копия корректно помечается устаревшей.
- Диагностика производительности включает обработку зимних окон, максимальную длительность кадра, количество кадров от 100 мс и число сборок мусора. Кадры длиннее секунды больше не исключаются из статистики.

Проверки: сборка против установленных DLL игры и MultiplayerAPI без предупреждений; 202 xUnit-теста, включая обмен хоста с двумя клиентами через новые объекты-обёртки каждого пакета и охлаждение кабины с включённой печкой. В Unity 2019.4.40f1 проверены реальные игровые типы дверей: внешний и постоянный интерьер, отделённый проём из entries, обратное направление управления, отсутствие повторных поисков и обновление после стриминга (`CAB_DOOR_BINDINGS_OK`).

В предоставленном клиентском логе также есть разовый скачок блока осенней листвы до 2487,98 мс. Журнал не доказывает единственную причину периодических фризов каждые две секунды. Уменьшение лишней работы и выделений памяти проверено по коду; устранение всех фризов требует повторной игровой проверки. Настоящая сессия на двух компьютерах при этой проверке не запускалась.

Обновить DVSeasons следует у хоста и всех клиентов. Формат сетевых пакетов (протокол 8), сохранений и пользовательских настроек не менялся.

Для Nexus: `DVSeasons-0.3.27-Nexus.zip`. Для распаковки и загрузки содержимого на GitHub: `DVSeasons-0.3.27-GitHub.zip`. Архивы цельные; каждый файл внутри меньше 100 000 000 байт.
