# Dynamic Seasons 0.3.1

- **Language Helper 1.2.1+ стал обязательной зависимостью.** Установите его отдельно через Unity Mod Manager перед запуском DVSeasons.
- Все 33 строки интерфейса, названия сезонов, статусы сети и погоды перенесены в CSV и загружаются через Language Helper.
- В комплекте русский и английский переводы. Язык меняется вместе с языком игры; если перевода нет, используется английский.
- Добавлена поддержка пользовательских переводов через источник **DVSeasons** в настройках Language Helper. Пересобирать DLL для изменения текста не требуется.
- CSV включён в архивы Nexus и GitHub. Сторонние DLL Language Helper в них не дублируются.

Подробнее: [инструкция для переводчиков](LOCALIZATION.md). Снежная система и остальные игровые функции 0.3.0 сохранены.

Проверки: Release без предупреждений и ошибок, 111 модульных тестов, проверка всех 33 строк и форматов CSV. В Unity Play Mode с настоящими DLL Language Helper 1.2.1 и I2 проверены смена RU/EN, форматы чисел, английский резервный перевод, русские и французские CSV-замены, перезагрузка и отсутствие дублирующихся источников. Полная игровая сессия не запускалась.
