# Dynamic Seasons 0.3.10

## Исправление отрисовки листвы

- Возвращена отрисовка обычных, лежащих и переносимых ветром листьев.
- Исправлена сетка листа: её CPU-данные теперь сохраняются после загрузки на GPU, как требует Unity `ParticleSystemRenderer` для mesh-частиц.
- Устранено предупреждение `No mesh data available for mesh DVSeasons curved autumn leaf`, из-за которого физика продолжала рассчитываться, но частицы не отображались.
- Скрытое боковое появление дополнительных листьев при сильном ветре и предел в 2200 листьев сохранены.
- Проверка проекта теперь запрещает повторное освобождение читаемой копии сетки листа.
