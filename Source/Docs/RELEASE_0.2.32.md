# DVSeasons 0.2.32 — плотный снежный шлейф

- Частота появления снежной пыли увеличена примерно вдвое по времени и более чем вдвое по пройденному расстоянию.
- Клубы стали крупнее, их плотная середина дольше сохраняет непрозрачность, а процедурные формы получили более заполненные края.
- Лимит увеличен с 600 до 900 короткоживущих частиц. Остаётся один эмиттер без физических столкновений.

Архивы: `DVSeasons-0.2.32-Nexus.zip` и `DVSeasons-0.2.32-GitHub.zip` (второй включает исходники).
